# Crypto Watchlist (CLI)

A simple Python command-line application to manage a cryptocurrency watchlist.

## Why this project

This project was built to practice Python fundamentals such as:
- functions
- file handling (JSON)
- CLI application structure

## Example

1. Bitcoin
2. Ethereum
3. Solana
4. ...

## Tech

- Python
- JSON

## Features

- Add coins
- Remove coins
- Display coin list
- Save & load data (JSON)

## Requirements

- Python 3.x
